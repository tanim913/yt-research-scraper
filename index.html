API keys

Add at least one key to start

Use a YouTube Data API v3 key from Google Cloud (not an AI key). Each key gives 10,000 units a day. Keys only add up when each one comes from a different Google Cloud project; keys in the same project share one quota.

New API key
Label optional, e.g. “lab project 2”
How do I get a key?
  1. Open console.cloud.google.com and create a project.
  2. Go to “APIs & Services → Library”, find YouTube Data API v3, press Enable.
  3. Go to “Credentials → Create credentials → API key” and copy it.
  4. Want more quota? Repeat with a new project and add that key too.

Research rules

Free to change: no quota used

Rules filter the videos already found, so changing them is instant and free. Leave a box empty to ignore that rule.

AI helper optional, free

Set up a free AI key

Gemini: make a free key at aistudio.google.com/apikey. OpenRouter: make a key at openrouter.ai/keys and use a model whose name ends in :free. Free plans allow only a few requests a minute, so big checks are slow.

What is sent: your topic text and, for the clean-up, video titles and channel names. Never comments and never your YouTube keys. The key stays in the data folder on this computer.

Clean comments

Remove spam and off-topic comments, label what script each comment is written in, and translate non-English ones. Your original comments.csv is never changed.

comments-clean.csv comments-removed.csv

Comments in Latin letters are kept as they are (this includes Bangla typed in English letters; a script cannot tell those apart). To get English versions of the rest, the AI helper can translate them. This sends the text of those comments to your AI service. Free plans take about 40 comments per request, so large sets are slow; you can stop and continue later.
